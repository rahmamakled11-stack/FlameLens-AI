# NASA Data Source Discovery Audit

**Review date:** 2026-11-15  
**Scope:** Official NASA sources relevant to FlameLens AI's microgravity combustion research. This is a source and access audit, not an authorization to ingest records or a claim that every named archive has a PSI record.

## Executive findings

1. NASA's [Physical Sciences Informatics (PSI)](https://psi.nasa.gov/physci/repo/search?q=&data_source=psi&data_type=investigation) repository is the primary discovery destination for physical-sciences investigations and datasets. NASA describes PSI as open access and says it includes data, simulations, and related research outputs across disciplines including Combustion Science. The repository is a public web application. During this audit, its search page rendered a JavaScript application; an official, supported public API contract, request limits, and stable export schema were not located.
2. NASA's [ISS Research Explorer](https://www.nasa.gov/mission/station/research-explorer/) is a complementary experiment-level discovery surface. NASA describes it as searchable for experiment objectives, descriptions, results, imagery, facilities, and related publications. The page inspected does not document a public API, pagination contract, or bulk export.
3. NASA's [NTRS search API](https://ntrs.nasa.gov/api/citations/search?q=combustion) returned JSON during this review, including a result count, citation metadata, abstracts, and public PDF/text download links where available. It is a technical-publication catalog, not an experiment registry or a source for assuming measured data.
4. NASA publishes an [Images and Video Library API document](https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf). This establishes an official API-documentation location, but the live API, current schema, authentication, rate limits, and any individual archive matches were not validated in this audit.
5. Short names are unsafe identifiers. An NTRS search for “ACME” returned an unrelated NASA additive-construction project. Resolve each candidate by full title, program, discipline, platform, NASA identifier, and source link before linking it to a combustion experiment.

### Interfaces, formats, and access constraints

- **Verified machine-readable response:** The NTRS citations search route above returned JSON in a live read. The response can include PDF/text download paths and a result total. The routes and result shape should be treated as observed behavior until NASA documentation confirms a stable integration contract.
- **Formats not confirmed:** No PSI XML/CSV export or stable file-format inventory was verified. Do not assume JSON, XML, or CSV from the appearance of the search interface; inspect each official record's actual download and file documentation. No XML/CSV capability was established for the other discovery pages in this review either.
- **Documented but not validated live:** NASA Images and Video Library publishes its API PDF. A separate API key, quotas, paging, and reuse rights were not verified here.
- **Public-facing web application, machine interface not verified:** PSI's investigation search. NASA describes PSI as public/open access, but public repository access does not imply a documented bulk API. Inspect each record's actual download controls and stated terms.
- **HTML discovery/context:** BPS program pages, ISS Research Explorer, and Task Book pages reviewed. No automation contract was found on the inspected landing pages.
- **Authentication:** PSI submission uses a NASA SSO portal, which is distinct from repository search. No access restriction for general PSI search was observed. NTRS search succeeded without a key. Other service authentication requirements remain unverified.
- **Limits and cadence:** No reliable public per-service request quotas, rate limits, or update cadence were found for PSI, NTRS, Images and Video, Research Explorer, or Task Book during this audit. Do not assume unlimited use; obtain current NASA guidance and use conservative request pacing.
- **Access restrictions and rights:** Public discoverability does not imply every document/file is public or reusable. Preserve distribution and rights metadata; never bypass sign-in, export-control, third-party rights, or repository controls.

## Field-level availability assessment

**Verified generally by official source description:** NASA's public descriptions support experiment objectives/descriptions/results/imagery/publications in the Research Explorer and datasets/simulations/research outputs in PSI. The NTRS sample confirms citation title, abstract, publication/report dates, author affiliation, categories, distribution, and possible file links in at least some records.

**Not verified universally:** A field being present on a portal overview does not mean every investigation has it, that it is machine-readable, or that it has comparable scientific data. Validate every mapped value against the selected record.

| Data sought | Best candidate source | Audit conclusion |
|---|---|---|
| NASA experiment title, NASA identifier, acronym, program/discipline, mission/platform | PSI record; ISS Research Explorer for station investigations; NASA project pages | Likely available for some records; exact identifier vocabulary, field names, and coverage require per-record inspection. Do not substitute PSI dataset IDs for an experiment identifier without explicit linkage. |
| Objectives, overview, methods, descriptions | ISS Research Explorer and PSI investigation pages; NASA project pages | NASA describes objectives and descriptions in the Explorer. Whether a page divides content into those named sections is record-dependent and not machine schema verified. |
| Results/findings | PSI datasets and related publications; ISS Research Explorer; NTRS/DOI landing pages | NASA says the Explorer includes results, and PSI provides research data/outputs. Interpret only source-attributed text or released data; no scientific finding can be inferred from a title or a search result. |
| Quantitative scientific measurements and conditions | Individual PSI dataset files and their documentation; primary papers | Not established by an investigation listing alone. Inspect file-level documentation for variable meaning, unit, conditions, uncertainty, calibration, and provenance. Do not create scalar metrics from chart images or abstract prose without a reviewed extraction protocol. |
| Publications, authors, journal, DOI, abstract | PSI related outputs/dataset citations, NTRS, DOI/publisher record, ISS Research Explorer | NTRS search returns publication metadata and abstracts for some records; PSI describes dataset DOIs. A DOI is not guaranteed. Verify each DOI and relation to the specific experiment. |
| Images/video and captions | ISS Research Explorer imagery; NASA Images and Video Library | Explorer is documented to surface imagery; NASA provides a media API document. Per-experiment matches, captions, thumbnails, and permissions were not verified. |
| Raw data files, simulations, analysis tools | PSI | NASA describes datasets, simulations, related outputs, and analysis tooling. Per-record available file types, variable schemas, access conditions, and licensing must be inspected. |
| Stable update/version timestamps | PSI, NTRS, source page | NTRS sample includes dates and a modified time. Stable version history and incremental update semantics for all sources were not verified. |

## Evidence classification and limitations

- **Verified available:** The official entry points listed above; NASA's description of PSI as open-access physical-sciences data repository; its Combustion Science discipline; the Explorer's high-level discovery categories; NTRS JSON search behavior and a sample result schema; existence of NASA Images API documentation.
- **Requires manual research:** Every named archive's exact NASA record, correct identifier, record-level metadata, actual files and their formats, data dictionary, source-to-experiment links, paper/DOI associations, and media matches.
- **Not established/unavailable from this review:** A public supported PSI API contract; stable PSI schema/bulk export; public ingestion API for Research Explorer or Task Book; current service quotas; universal record completeness; quantitative results for any named project; and universal DOI or media coverage. “Not established” means not verified here, not proof that NASA does not provide it.
- **Assumptions to verify before implementation:** NASA access and reuse terms for each file; API availability/versions and request limits; whether search may be automated; whether values in PSI files can be normalized with sufficient unit/condition metadata; and whether NASA identifiers are unique across these repositories.
